# Archive — historical snapshots

These are frozen, point-in-time documents: planning records, one-off audits,
and handoff briefs from the 2026-06 v2 cutover (and a little earlier). They are
kept for provenance — "how did we get here" — and are **deliberately not
maintained**. Where they disagree with the live docs or the code, the live docs
and code win.

For current truth, start at the [docs index](../README.md) and
[tech-stack.md](../tech-stack.md).
