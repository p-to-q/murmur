9. 使用说明

本素材库包含了 Murmur 产品中所有可提取的 CSS 组件、视觉动画和 UI 模式。 你可以直接复制 CSS 代码段到你的演示文件中使用。

主演示文件：pitch/index.html — 包含 11 页完整答辩 PPT，已配齐所有效果和叙事文本。
素材库文件：pitch/effects-library.html — 即本文件，提供独立的组件示例。

使用流程：
1. 打开 pitch/index.html 在浏览器中预览
2. 按 → ← 或 Space 切换幻灯片
3. 按 N 打开演讲者提示
4. 将 HTML 注释中的叙事选项取消注释以切换不同文本
5. 替换 asset-placeholder 中的内容为你的真实素材
